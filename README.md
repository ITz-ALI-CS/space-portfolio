## ✨ Features
- Real 3D planet that flies to a new spot as you scroll
- **4 worlds** that change with the page colors: Aurora Giant, Ember Mars, Blue Ocean and Crystal Nebula
- Interactive sky: dust that parts around the cursor, hold to pull the stars, drag to spin the planet
- Click the planet to bounce it, send out a shockwave and switch worlds
- Comets, shooting stars, asteroid belt and **warp speed**
- Animated name, typing headline and a self-typing terminal
- Animated architecture diagram: Frontend → Backend → Database + AI
- Project filters, 3D tilt cards and live GitHub repo counter
- Mission-control HUD, loading screen, smooth scrolling and ambient sound

## ⌨️ Controls
`W` warp • `C` comet • `1`-`4` change world • `M` sound • drag the sky to spin
